Онлайн-арена. Другу нужен только браузер с WebGL2 и ссылка на ваш сервер.

В той же Wi-Fi сети (только хосту нужен Python 3.10+):
1. Откройте терминал в распакованной папке рядом с server.py.
2. python -m pip install -r requirements.txt
3. python server.py
4. Хост: http://localhost:8765 . Друг: http://LAN-IP-хоста:8765 (например, http://192.168.1.23:8765). Разрешите входящие подключения для частной сети, не закрывайте терминал.

Через интернет: разверните содержимое этой папки как один Python Web Service с поддержкой WebSocket. Конфигурация render.yaml включена. Файлы server.py, requirements.txt, render.yaml и папка site должны лежать в корне деплоя. Команда сборки: pip install -r requirements.txt . Команда запуска: python server.py . Номер порта берётся из PORT. Сервис должен быть запущен в одном экземпляре, список комнат хранится в памяти. Оба игрока открывают один и тот же HTTPS-адрес. Никакого отдельного сайта или ручного адреса /ws не нужно.

В меню выберите «Мультиплеер», разные ники и одну комнату. Можно создать комнату с паролем. Сетевая игра — на арене, не в сюжетном прологе.

ОБНОВЛЕНИЕ СЕТИ 2.0. Замените файлы старого проекта содержимым архива, в том числе site/game.js, server.py и arena_net.json. В Render: Build Command = pip install -r requirements.txt; Start Command = python server.py; Manual Deploy → Deploy latest commit. После деплоя проверьте /health: поле version должно быть 2.0. Обоим игрокам перезагрузить вкладки (Ctrl+F5). Сеансы и комнаты в памяти сервера при деплое сбрасываются.
